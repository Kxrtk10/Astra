# How to add 3D avatars to Astra

1. Go to https://readyplayer.me
2. Create a free account
3. Create an avatar matching the tutor personality
4. Export it as a GLB file
5. Name it `calm_mentor.glb`, `sharp_strategist.glb`, or `friendly_senior.glb`
6. Place the file in the `web/avatars/` folder
7. Restart the server
8. Astra will automatically load the 3D avatar

Until GLB files are added, Astra will automatically use the existing 2D tutor face images with a speaking glow animation.
